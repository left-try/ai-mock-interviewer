# Запуск Backend Internship HR MVP

## Установка

Нужен Python 3.11 или новее. В PowerShell из корня репозитория установите пакет:

```powershell
python -m pip install -e ".[test,voice-probe]"
```

MCP-сервер запускается существующей командой `python tools/voice_probe.py`. Она совместима с уже настроенным Codex MCP-подключением `interviewer-probe` и теперь публикует как инструменты проверки голоса, так и интервью.

После установки перезапустите Codex Desktop, чтобы MCP-клиент перечитал список инструментов. В проекте доступен skill `backend-internship-interviewer`; запустите его голосом или попросите Codex провести практическое HR-интервью на Backend Internship.

## Как проходит интервью

1. Передайте синтетическое резюме или вставьте текст. Текущие MCP-инструменты принимают текст резюме; Python-сервис отдельно умеет извлекать текст из PDF и DOCX через `start_from_upload`.
2. Хост голосового режима предлагает первый вопрос и передаёт его через `start_interview`.
3. После каждого финализированного ответа хост один раз вызывает `record_candidate_answer`, передавая исходный текст, новый `event_id` и структурированное предложение следующего вопроса. Повтор с тем же идентификатором идемпотентен.
4. Скажите, что интервью завершено. Хост передаёт предложение отчёта в `finish_interview`; сервис проверяет критерии, оценки, ссылки на ходы и цитаты.
5. Чтобы удалить резюме и транскрипт из памяти MCP-процесса, вызовите `delete_interview`. Отмена также удаляет сессию. При завершении процесса Codex состояние теряется.

Голос и генерацию текста обеспечивает модель, уже работающая в Codex Voice по подписке. Локальное приложение не подключается к API-модели и не получает сырой аудиопоток: оно хранит финализированный текст и проверяет переходы. Поэтому корректность распознавания и надёжность вызовов инструмента зависят от голосового клиента.

## Проверка

```powershell
python -m pytest
```

В наборе есть одна противоречивая фикстура: `test_finish_returns_report_and_marks_session_completed` вызывает `finish` без ответа кандидата, но требует принять доказательство из несуществующего `turn-2` и цитату, которой нет в резюме. Сервис намеренно отклоняет такой отчёт. Остальные контракты должны проходить без изменения тестов; этот fixture/spec конфликт нужно исправить до требования полностью зелёного набора.

Для проверки доступности MCP-инструментов в Codex Desktop откройте новый чат проекта после перезапуска клиента. Для голосовой проверки используйте только вымышленные данные.
