# Product backlog

Backlog фиксирует расширения исходной идеи. MVP scope находится в [docs/MVP.md](docs/MVP.md); пункты ниже не являются обещанием очередности или реализации.

## Исследовать в первую очередь

- [x] Проверить Codex Voice → local MCP transcript probe: финализированный текст и ровно одна запись на ответ.
- [ ] Пройти полное MVP-интервью через новые MCP-инструменты голосом: follow-up, завершение, отчёт, отсутствие утечки критериев; отдельно оценить перебивания, ошибки, лимиты и стоимость.
- [ ] Сравнить варианты голосового транспорта: встроенный голосовой режим хоста, отдельный speech-to-speech/API и локальный режим; сравнить задержку, стоимость, качество русского языка и контроль над сессией.
- [ ] Уточнить MVP-критерии оценки HR-интервью для стажёра Backend на примерах ответов и собрать небольшой набор эталонных сценариев.
- [ ] Проверить качество разбора PDF/DOCX резюме и подход к чувствительным персональным данным: согласие, срок хранения, удаление и журналирование.

## Продуктовые расширения

- [ ] Добавить уровни Backend: Junior, Middle, затем Senior и Staff.
- [ ] Добавить специализацию Applied AI для тех же уровней.
- [ ] Добавить этапы интервью как конфигурируемые сценарии: HR, recruiter screen, behavioral, техническое интервью, live coding, system design и иные этапы.
- [ ] Настраивать вопросы, скрытый план, критерии, тайминг и правила follow-up отдельно для каждой комбинации роли, уровня и этапа.
- [ ] Дать пользователю выбрать длительность, язык, строгость интервью и возможность повторить отдельный этап.
- [ ] Сохранять историю сессий, прогресс и сравнение результатов при явном согласии пользователя.

## Инструменты по типу этапа

- [ ] Live coding: встроенное или интегрированное рабочее место для кода; наблюдение за кодом и его изменениями; обсуждение решений в реальном времени.
- [ ] System design: интерактивная доска для схем и текстовых заметок; разбор действий и объяснений кандидата.
- [ ] Определить модель подключения наблюдателя к рабочему месту: структурированный доступ к DOM/событиям там, где это возможно; OCR/vision только когда состояние доски нельзя получить надёжнее напрямую.
- [ ] Провести privacy review для доступа к браузеру/экрану, записи аудио и хранения артефактов.

## Качество и эксплуатация

- [ ] Проверить устойчивость к попыткам извлечь скрытый план из модели и пользовательского интерфейса.
- [ ] Калибровать оценки на согласованных примерах; показывать основания и неопределённость вместо псевдоточного балла.
- [ ] Добавить защиту от выдуманных фактов резюме и ответов, а также проверку согласованности отчёта с транскриптом.
- [ ] Добавить доступность, субтитры/текстовую альтернативу и восстановление после обрыва голосового соединения.
- [ ] Определить метрики качества интервью без сбора лишних персональных данных.
